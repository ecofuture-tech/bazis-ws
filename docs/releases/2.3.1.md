# bazis-ws 2.3.1

## Fixes

- 2.3.0 looked the user of a session token up by `USERNAME_FIELD` of the user model, while
  the token (`jwt_build` of bazis-users) and bazis-users use `username`: with a user model
  whose `USERNAME_FIELD` is another field, every session failed with `user_not_found`. The
  user is looked up by `username` again, as in 2.2.
- The asyncio Redis clients of closed event loops were never released.
- README: the channel names are `user_ws::<id>` and `user_ws::<id>:session`, and the JWT
  library is PyJWT.
