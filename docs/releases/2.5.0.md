# bazis-ws 2.5.0

Requires Bazis 2.4.

## Security

- Anonymous sessions no longer receive the common channel `user_ws:common`: an anonymous
  token is generated by the client, so anybody could open a session and read everything
  published there. User sessions (a session JWT) receive it as before. The new setting
  `BS_BAZIS_WS_ANONYMOUS_COMMON_CHANNEL=true` restores the previous behavior for projects
  whose common channel is public. Publish on the common channel only
  `{"resource": "<JSON:API type>"}` (no ids); the ids and the notifications go to the users
  who may see the item with `user.ws_publish(...)`.

## Protocol

- `{"type": "subscribed"}` is sent once the subscription of a session is active (after
  each accepted token): the messages published from then on are delivered. Clients should
  wait for it instead of treating the first `pong` as the proof of the session.
- A socket is no longer left open without a session after an error: a refused token
  (`expired_token`, `invalid_token`, `user_not_found`) closes it with code 1008 (connect
  again only with another token), `internal_error` closes it with code 1011 (reconnect with
  a growing delay), as a Redis failure already did. A client that sent a refused token can
  no longer send another token on the same socket: it opens a new connection. The messages
  the client sent after the close are ignored.

## Setup

- The guide and the sample register `ws_route` in the router module of the project
  (`BS_BAZIS_ROUTER_MODULE`, `router.routes.append(ws_route)`; the path stays `/ws`), which
  tools such as the contract export of bazis-front import. A route appended to the
  application in the main module still works at runtime, but the tools do not see it.

## Compatibility

- A project that lists its Bazis packages in `BS_BAZIS_APPS` loads the new setting only if
  it lists `bazis.contrib.ws`; without it the secure default (`false`) applies.
- `WsEndpoint` gained the attribute `receives_common`; the private `_fail(websocket)` became
  `_close(websocket, code)`.
