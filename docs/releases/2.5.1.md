# bazis-ws 2.5.1

Documentation only; the code is the one of 2.5.0.

## Documentation

- The guide (`bazis/contrib/ws/AGENTS.md`) and the manifest say how a write publishes:
  from the hooks of the write (not `validate_item`, which may run more than once), after
  the commit, robustly, with the values bound early
  (`transaction.on_commit(partial(user.ws_publish, message), robust=True)`; tested), and
  give the notification format of bazis-front
  (`{"action": "notification", "title", "text", "resource", "id"}`) with its texts in the
  language of each user (`translation.override(user.language or settings.LANGUAGE_CODE)`).
  The trial agent copied both from the sample of bazis-front.
