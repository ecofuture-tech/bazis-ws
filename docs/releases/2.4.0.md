# bazis-ws 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (setup, the protocol, publishing and the security rules
  of the channels) and `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md`
  of Bazis); `tests/test_manifest.py` verifies the manifest.
